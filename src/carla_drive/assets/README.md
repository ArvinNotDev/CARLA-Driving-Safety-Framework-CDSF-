# Horn sound

`car_horn.wav` is a short crop of the first horn from “Car Horn.wav,” recorded by 15HPanska_Ruttner_Jan and published on Wikimedia Commons under CC0 1.0. The clip was trimmed to one horn burst, converted to mono 22.05 kHz PCM, and given short fades to avoid clicks when it loops while R3 is held.

Source: https://commons.wikimedia.org/wiki/File:Car_Horn.wav
